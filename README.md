# Куда пойдём?
Сайт о городских планах в Москве.

[Открыть опубликованный сайт](https://kuda-poydem-moscow-evening.relaxedant32.chatgpt.site) · доступ определяется настройками Sites.

![Интерфейс на 1440 px](docs/preview.png)
 Новый первый экран вдохновлён предоставленным референсом: собственная фотографическая сцена, персиковая палитра, крупная типографика и фиолетовые акценты. Макет проверен на 1440×900 и 390×844.

## Запуск
Нужен Node.js 24+ (встроенный SQLite используется только в тестах и локальном предпросмотре).
- `node scripts/preview.mjs` — http://localhost:8080, временная база в памяти.
- `node --test tests/*.test.mjs` — проверки подбора, регистрации, сессий, избранного и восстановления.
- `node scripts/build.mjs` — Worker `dist/server/index.js` с встроенными ассетами. Зависимости не требуются.

Редактируемые исходники: `web/` и `server/`; `dist/` генерируется. В `.openai/hosting.json` намеренно не указан project_id: для собственного развёртывания создайте отдельный проект Sites и добавьте выданный идентификатор. D1 binding: `DB`, схема находится в `drizzle/0000_accounts.sql`, применяется Sites при публикации. Локальная и опубликованная базы раздельные.

## Возможности
- Настроение, бюджет, компания, дата/время Москвы, пять станций метро.
- Одна случайная подходящая активность, с исключением предыдущего результата при наличии альтернатив.
- Избранное в браузере для гостей, серверное избранное после входа.
- Три разные активности в одном районе. Учитываются суммарные траты на человека, длительность, переходы и ориентировочные окна доступности.
- Почасовые температура, ветер, порывы и вероятность осадков от Open-Meteo. Сильный ветер, мороз или высокая вероятность осадков исключают улицу; проверяется всё время активности. Без прогноза это явно указано.
- Регистрация по логину и паролю, вход/выход. Пароли хранятся как PBKDF2-SHA512 с индивидуальной солью. Сессии — случайные токены, в базе только хеши; cookie HttpOnly, Secure, SameSite. Проверка Origin на записях и лимит попыток авторизации.
- Восстановление одноразовой ссылкой на 30 минут, отзыв всех сессий после смены пароля. Без настройки почты API отвечает явной ошибкой недоступности, письмо не имитируется.

## Подключение почты
Пользователь выбрал подготовку подключения без почтового сервиса. Подготовлен адаптер Resend. После регистрации сервиса и подтверждения домена задать секреты через Sites environment variables:
- `RESEND_API_KEY` — ключ с правом отправки писем.
- `MAIL_FROM` — подтверждённый адрес, например `Куда пойдём <hello@your-domain.ru>`.
После настройки опубликовать версию с новой ревизией окружения. Не помещать ключ в репозиторий, браузер или переписку. Отправка писем не проверена с реальным провайдером, пока его нет.

Документация: https://resend.com/docs/api-reference/emails/send-email и https://developers.cloudflare.com/workers/runtime-apis/web-crypto/.

## Границы подбора
Каталог содержит редакционные идеи в районах метро, а не живую базу бронирований. Карта открывает поиск конкретного места. Часы, траты, координаты районов и минуты ходьбы приблизительны; доступность заведений и мероприятий не подтверждается автоматически. Фото карточек атмосферные, не фотографии конкретных заведений. Поиска людей, чата, записи на мероприятия и гарантии знакомств нет. Прогноз для центра Москвы не моделирует ветер в отдельных дворах и не гарантирует безветрие. Для коммерческой эксплуатации проверить применимые условия погодного API: https://open-meteo.com/en/docs.
