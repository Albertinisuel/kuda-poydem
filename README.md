**[Открыть готовый сайт на GitHub Pages →](https://albertinisuel.github.io/kuda-poydem/)**

Городские планы Москвы под настроение, погоду и компанию. Многостраничный сайт: главная, подбор активности, каталог, избранное, план вечера, личный кабинет. Общая навигация и адаптивный интерфейс, основанный на утверждённом изображении с исправленными руками. Заголовок первого экрана — «У города есть / планы на вас» в две строки.

## Запуск и сборка

Нужен Node.js 24+ для тестов (встроенный SQLite нужен только проверкам серверного кода). Пакетов и ключей для запуска интерфейса не требуется.

```bash
npm run build
npm run preview
npm test
```

Предпросмотр: http://127.0.0.1:8080/kuda-poydem/.

Редактируемые файлы интерфейса лежат в `web/`. `scripts/build-pages.mjs` собирает шесть отдельных HTML-страниц и общие ассеты в `docs/`. Ссылки относительные, поэтому сайт работает и под префиксом `/kuda-poydem/`. `docs/.nojekyll` отключает обработку Jekyll.

## Публикация на GitHub Pages

В настройках этого репозитория: **Settings → Pages → Deploy from a branch → main → /docs → Save**. После обновления исходников выполнить `npm run build` и загрузить изменённые файлы `web/` и `docs/` в репозиторий. GitHub опубликует новую версию автоматически.

## Что работает на опубликованном сайте

- Отдельные страницы с общей навигацией, мобильное меню и карточки с подробностями.
- Случайная идея по настроению, компании, бюджету, станции метро, дате и времени Москвы.
- Каталог с поиском, фильтрами настроения, метро и типа пространства.
- Избранное в браузере, сохранение при переходах и обновление между вкладками.
- Три разные активности у одной станции с учётом общего бюджета, продолжительности, переходов и ориентировочных окон доступности. План можно сохранить и скопировать.
- Сохранение выбранных пожеланий и последнего плана на этом устройстве.
- Почасовые температура, ветер, порывы и вероятность осадков от Open-Meteo. Сильный ветер, мороз и высокая вероятность осадков исключают улицу; проверяется всё время активности. Отсутствие прогноза явно обозначается.

## Аккаунты и почта

GitHub Pages — статический хостинг, он не выполняет серверный код. В опубликованной версии логин, регистрация и восстановление по email **не включены**. Это явно указано в личном кабинете; формы отключены, пароль не собирается и не сохраняется в браузере. Избранное и планы доступны без аккаунта и хранятся только на устройстве пользователя.

Серверная реализация сохранена в `server/auth.js`, миграции в `drizzle/`, тесты в `tests/auth.test.mjs`. Для настоящих аккаунтов потребуется самостоятельно разместить API и базу данных, настроить CORS и cookies для выбранных доменов, затем указать HTTPS-адрес API в `web/config.js` и завершить интеграцию синхронизации избранного. Сервер не подключается к старому хостингу автоматически. Для восстановления пароля также нужны почтовый сервис, подтверждённый адрес отправителя и секреты `RESEND_API_KEY` / `MAIL_FROM` на сервере. Секреты не должны попадать в GitHub или браузер.

Серверные тесты проверяют хеширование паролей, регистрацию, вход, защиту избранного, лимит попыток, одноразовость ссылок и отзыв сессий. Они не означают, что API размещён на GitHub Pages.

## Границы подбора

Каталог содержит редакционные идеи в районах метро, а не живую базу заведений и бронирований. Карта открывает поиск конкретного места. Часы, траты, координаты районов и минуты ходьбы приблизительны. Доступность мест и мероприятий автоматически не подтверждается. Фото карточек атмосферные. Поиска людей и гарантии знакомств нет. Прогноз центра Москвы не моделирует ветер в отдельных дворах и не гарантирует безветрие. Условия погодного API: https://open-meteo.com/en/docs.

Главная иллюстрация: `web/assets/evening-hero-v3.jpg`. Создана встроенным ImageGen по утверждённому изображению: убраны надписи и элементы интерфейса, сохранены сцена и естественное положение двух рук. Тексты и кнопки поверх фона свёрстаны в HTML/CSS.
